<h2>Overview</h2>
<h3>The Challenge</h3>
Users should be able to:
<ul>
<li>View the optimal layout for the app depending on their device's screen size</li>
<li>See hover states for all interactive elements</li>
<li>Select and submit a number rating</li>
<li>See the "Thank you" card state after submitting a rating</li>
</ul>

<h3>What I Learned</h3>
<p>
While building this project, I learned how to manage dynamic UI states using plain JavaScript.
I used event listeners to detect the selected rating and update the DOM to switch between the rating card and the thank-you card.
</p>
<p>
This helped me understand:
</p>
<ul>
<li>How to toggle between two UI states using the <code>display</code> property</li>
<li>How to loop through a group of buttons with <code>forEach</code> to reset and apply active styles</li>
<li>How to dynamically update text content based on user interaction</li>
</ul>
